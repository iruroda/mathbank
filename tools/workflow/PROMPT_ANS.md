# 정답 읽기 작업 (해설 PDF 의 정답표 → JSON)

서브에이전트에게 줄 때: "이 파일을 먼저 읽고 [연도·월] 정답 JSON 을 만들어라". 저장소 $REPO, 출력 $WORK/ans/.
해설 PDF: $REPO/pdf/{연도}/{연도}_{학년}학년_{월}월[(가형|나형)]_해설.pdf

## 방법
- 우선 `python3 $REPO/tools/extract_answers.py {연도} {학년} {월}` 로 자동 추출을 시도한다 (EBSi 해설 정답표용; 한글 수식 글꼴 숫자는 0~9 로 환산). 결과는 **반드시 그림과 대조**한다.
- 자동 추출이 안 되거나 스캔본이면: pypdfium2 로 쪽을 그림으로 만들어(`python3 -c "import pypdfium2 as p; d=p.PdfDocument(PATH); d[i].render(scale=1.6).to_pil().save('/tmp/x.png')"`) Read 로 보고, 표가 작으면 그 부분만 crop 해 scale 3~4 로 키워 읽는다.
- 정답 형식: 선택형 ①②③④⑤ 문자, 단답형 숫자 문자열("25"). 보통 선택형은 공통 앞부분, 단답형은 뒤. 문항 모양과 맞는지(선택형인데 숫자, 단답형인데 ①) 검사한다. 불확실하면 풀이를 따라가 확인한다.
- 같은 번호 해설이 쪽에 걸쳐 있어도 정답은 하나.

## 출력 형식 ($REPO/data/answers_<이름>.json 에 시험 키로 합치거나, 먼저 $WORK/ans/ 에 시험별로 쓴다)
키는 "연도-학년-월"(월 앞 0 없음; 가/나·A/B 형이면 "-ga" "-na" "-A" "-B" 를 붙임). 예: "2026-3-10", "2026-1-10", 2006-3-04-ga.
- 1·2학년·단일 시험지: {"1":"③","2":"⑤",...,"30":"24"}  (1~30 모두)
- 3학년 2021~(공통+선택): {"공통": {"1":..,"22":..}, "확률과 통계": {"23":..,"30":..}, "미적분": {...}, "기하": {...}}  (공통 22 + 선택 각 8 = 30 문항 구성; 시험마다 시험지에서 번호 범위를 확인)
- 7차 가형(2006~2010, 3월 제외): {"공통": 1~25, "미분과 적분": 26~30, "확률과 통계": 26~30, "이산수학": 26~30}; 3월 가형·나형은 평평한 1~30.
- 모든 값은 문자열, 유효한 JSON. 새 데이터 파일은 data/answers_*.json 이름이면 build_all.py 가 자동으로 읽는다 (키가 겹치면 나중 파일이 덮어씀).
- 마지막 답변: 시험별로 "확신 낮은 번호"만 짧게 (없으면 '없음').
