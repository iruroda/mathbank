# 분류 작업 지침 (전국연합·모의평가·수능 문항 → 2022 개정 성취기준 코드 + 배점 읽기)

서브에이전트에게 줄 때: "이 파일을 먼저 읽고 그대로 따라 [폴더명 목록]을 처리하라" 로 지시한다. $WORK 는 보통 /tmp/mbwork (crop_new.py 가 만든 곳), 저장소 경로는 $REPO (예: /home/claude/mathbank).

각 시험 폴더 $WORK/cls/{폴더명}/ 안에 문항별 PNG 가 있다. 폴더명: {연도}_{학년}_{월2자리}[_ga|_na|_A|_B]  (예: 2026_3_10, 2026_1_10)
파일명(=JSON 키): C01~C30(공통·1·2학년·단일 시험지), 3학년 2021~(2022 개정형) 선택과목은 P23~P30(확률과 통계) K23~K30(미적분) G23~G30(기하)처럼 구역 글자+번호. 7차 3학년 가형(2006~2010)은 D26~D30(미분과 적분) P26~P30 S26~S30(이산수학) 도 있다.
**모든 PNG 를 Read 로 직접 열어 눈으로 보고** 문항마다 성취기준 코드 1개를 고른다 (파일명·번호로 추측 금지). 여러 장을 병렬로 Read 하면 빠르다. 폴더에 있는 PNG 만 처리한다 (가/나형 중복 문항은 이미 뺐으므로 번호가 비어 있어도 정상).

## 코드 목록
- 고등학교 시험: $REPO/tools/workflow/codes_hs.txt   / 1학년 3월(중학교 범위)만 codes_ms.txt. 목록 그대로의 코드만 쓴다 (형식 예: 12대수01-03, 12미적Ⅰ-02-04, 9수01-01).
- 원순열은 목록에 없으므로 예외로 "12이수01-01" 을 쓴다.

## 분류 원칙
- 학생이 그 문항을 풀기 위해 **배워야 하는 단원**(학습 순서가 가장 나중인 개념) 기준. 경우의 수 → 확률 → 통계 순. 정적분 함수의 미분이면 미적분 쪽.
- 여러 개념이 섞이면 학습 순서가 가장 나중이고 풀이의 핵심인 개념의 코드, 필요하면 note 에 한 줄(없으면 "").
- 3학년 선택과목 문항(P/K/G)은 해당 과목 코드를 우선. 풀이의 핵심이 다른 과목이면 그 코드 + note 에 이유.
- 맞는 항목이 없으면 가장 가까운 코드 + note (옛 교육과정의 행렬·상용로그 등).
- summary: 문항이 묻는 핵심을 20자 안팎의 한국어 명사구 (예: "다항함수의 도함수와 미분계수 계산").
- 옛 교육과정(2006~2020) 문항 대응: 수학Ⅰ(지수·로그·삼각·수열) → 대수, 수학Ⅱ(극한·미분·적분) → 미적분Ⅰ, 수열의 극한·여러 가지 미분/적분 → 미적분Ⅱ, 이차곡선·벡터·공간도형 → 기하, 순열·조합·확률·통계 → 확률과 통계, 집합·명제·함수 → 공통수학, 7차 이산수학 → 12이수 코드.

## 추가 출력: 배점과 이상 표시
- **"points"**: 문항 그림 안의 "[2점]" "[3점]" "[4점]" 을 2·3·4 숫자로. 읽을 수 없으면 null. (텍스트 PDF 는 검출 단계에서 이미 읽지만 그림 PDF 는 이 값이 쓰인다.)
- 그림이 잘렸거나 앞 문항 일부·머리글·쪽번호·안내 상자("단답형", "확인 사항", 선택과목 안내)가 섞였거나 문항 둘이 합쳐졌거나 빈 곳이 지나치게 길면 note 맨 앞에 "[CROP] 이유". 이상 없으면 쓰지 않는다. ([CROP] 은 merge_cls.py 가 note 에서 지운다.)

## 출력
시험마다 JSON 1개: $WORK/out/{폴더명}.json  — 키는 폴더 안 PNG 이름에서 .png 를 뺀 것 전부:
{"C01": {"code": "12대수01-03", "summary": "유리수 지수를 포함한 거듭제곱의 계산", "note": "", "points": 2}, ...}
검증: `WORK=$WORK python3 $REPO/tools/workflow/validate_cls.py {폴더명}` → OK 가 나올 때까지 고친다.
최종 답변은 "완료: 폴더 목록" + [CROP] 문항(폴더명 번호 이유) 한두 줄만.
