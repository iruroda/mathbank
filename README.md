# mathbank — 전국연합 학력평가 문제은행

체크한 문제만 모아 **한 쪽에 2문제(또는 4문제)** 씩 배치하고, **해설은 미주**로 붙인 PDF 를 만드는 정적 웹앱입니다.
서버 없이 브라우저에서 `pdf-lib` 로 PDF 를 조립합니다 (원본 PDF 를 문제 단위로 잘라 벡터 그대로 붙이므로 확대해도 깨지지 않습니다).

## 구조
```
index.html, js/            웹앱 (js/layout.js = 쪽 배치 계산, js/app.js = 화면 + PDF 조립)
vendor/pdf-lib.min.js      PDF 조립 라이브러리 (오프라인에서도 동작하도록 동봉)
pdf/<연도>/                원본 시험지 PDF  (예: pdf/2021/2021_1학년_6월_문제.pdf, ..._해설.pdf)
data/problems.json         문제별 위치(좌표)·단원·성취기준·배점·정답  ← 웹앱이 읽는 데이터
data/classification_2021_06.xlsx, data/classification/*.json  단원 분류 원본 (시험 1회 = 파일 1개)
data/classification_all.xlsx  전체 분류표 (tools/make_xlsx.py 로 생성)
data/detect/<시험>.json    문제·해설 영역 검출 결과 캐시 (검출 코드를 고쳤을 때만 build_all.py --redetect)
data/standards_codes.json  성취기준 코드 → 과목·단원·문장 사전
data/answers_*.json        정답표 입력본
tools/                     좌표 자동 검출·데이터 생성 스크립트 (Python)
```

## 로컬에서 실행
브라우저는 `file://` 로 연 페이지에서 PDF 를 읽지 못하므로 간단한 서버가 필요합니다.
```
python -m http.server 8000     # 저장소 폴더에서
# 브라우저에서 http://localhost:8000
```
GitHub Pages 로 배포하면 그대로 동작합니다.

## 새 시험 추가 절차
1. `pdf/<연도>/` 에 `<연도>_<n>학년_<월>월_문제.pdf`, `..._해설.pdf` 를 넣는다.
2. 단원 분류 json(`data/classification/`)과 정답 json(`data/answers_*.json`)을 준비한다.
3. `tools/build_all.py` 의 `EXAMS` 목록에 시험을 추가하고 `python tools/build_all.py` 로 (처음 보는 시험은 자동으로 검출해 캐시에 저장) `data/problems.json` 을 다시 만든다 (문제·해설 영역 자동 검출).
4. `tools/overlay.py` 로 잘린 영역을 눈으로 확인한다. 전체 분류표는 `python tools/make_xlsx.py` 로 만든다.

## 알려진 한계
- 정답은 해설 정답표를 눈으로 옮기고 해설 PDF 텍스트와 대조한 값입니다.
- 2021학년도 3학년 7월 해설은 새 파일로 교체되어 확률과 통계·미적분·기하 해설이 모두 포함됩니다.
- 2022학년도 3학년 6·9·11월 시험은 평가원 모의평가·수능(EBS 해설) 형식입니다.
- 2023~2026학년도(2026학년도 9월까지) 1·2·3학년 시험이 추가되었습니다(2026학년도 10·11월은 아직 시행 전). 3학년 EBSi 해설은 공통+선택(확통/미적분/기하) 해설을 한 파일로 합쳤고, 선택과목 해설이 쪽 중간에서 시작하는 시험은 공통 해설 쪽을 중복으로 붙였습니다(검출 시 마지막 문항 뒤의 중복 쪽은 잘라 냅니다).
- 2023~2026 정답은 해설 정답표에서 `tools/extract_answers.py` 로 읽고(한글 수식 글꼴의 숫자 코드는 0~9로 환산), 문항 유형(선택형 ①~⑤ / 단답형 숫자)과 대조해 검증했습니다. 단원 분류는 문항 이미지를 보고 매겼으므로 애매한 문항은 note 열을 참고하세요.
- 2020학년도(2015 개정) 3학년은 가형/나형 별도 시험지입니다. 두 시험지의 동일 문항은 가형만 수록하고, 같은 지문이 단답형·선택형으로 나뉜 쌍은 단답형만 수록합니다(`data/dup2020.json`: same/variant/delete). 수록된 문항에는 `also`(예: "나형 12번")가 붙고 PDF 라벨에는 "(=나12)"로 표시됩니다. 화면의 '형(가/나)' 필터로 선택할 수 있습니다.
- 2020학년도 3학년 11월 문제지는 글자가 없는 이미지 PDF라 `tools/detect_img.py`(이미지 분석)로 문항을 잘랐고, 배점·형식은 수능 구성(1~3번 2점, 4~13번 3점, 14~21번 4점, 22~25번 3점, 26~30번 4점)으로 정했습니다.
- 2020학년도 3학년 6·9·11월은 평가원 모의평가·수능(EBS 해설) 형식입니다. 해당 시험지의 표지에는 "2021학년도"로 적혀 있는데, 2020년에 치러 다음 학년도(2021학년도) 대학 입학생을 선발하는 시험이기 때문입니다.
- 2020학년도 3학년 10월 나형 15번은 요청에 따라 삭제했습니다(교육청 전원 정답 처리 문항).
- 저작권: 시험지 저작권은 출제 기관에 있으므로 저장소를 비공개로 두거나 교내 사용 범위를 지키세요.
